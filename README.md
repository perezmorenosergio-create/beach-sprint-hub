# Beach Sprint Hub v3.0 — Perfil entrenador / Planificación anual

Primer módulo real de la super app.

Incluye:
- Importación de Excel anual con hojas Summary, Plan y Training.
- Visión anual de semanas, cargas, fases, macrociclos y competiciones.
- KPIs de semanas, horas, sesiones y eventos.
- Detalle de cada semana con sesiones, RPE y zonas.
- Resumen semanal por Z1-Z6, fuerza y otros.
- Biblioteca de tipos de sesión con buscador.
- Conservación local del plan importado para no repetir la carga.

La siguiente fase conectará cada planificación a un deportista y a Supabase.
